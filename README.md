# KiwiCaptcha

A privacy-first, self-contained **proof-of-work CAPTCHA engine**.

**Zero external services. Zero tracking. No iframes. No third-party hosts.**
The widget is an inline nonce'd script that solves a SHA-256 (or memory-hard
Argon2id) proof-of-work using an embedded WASM solver with a pure-JS
fallback — the challenge is HMAC-signed, single-use, IP-bound, and TTL'd.

## Why

Hosted CAPTCHAs (reCAPTCHA, hCaptcha, Turnstile) leak every page view to a
third party, break under strict CSPs, and charge per solve. KiwiCaptcha is a
native, self-hosted alternative:

- **Quantum-safe SHA-256 PoW** — a hash function, not a factoring/discrete-log
  scheme (the "quantum-resistant" property is not a design goal; the hash is
  simply what it is, and Argon2id adds ASIC/GPU resistance).
- **Memory-hard Argon2id mode** — optional, defeats specialized hardware.
- **Explicit algorithm dispatch** — every challenge carries its algorithm
  (`sha256` / `argon2id`); the solver and verifier can never disagree.
- **Hardened bot detection** — webdriver flag, behavioral entropy over discrete
  events (coefficient-of-variation rule immune to mousemove coalescing and OS
  key auto-repeat), long-headless-solve rejection.
- **Per-challenge minimum solve duration** — derived from the issued
  difficulty, so auto-tuning can never collide with the floor.
- **Bounded verification cost** — per-nonce attempt caps prevent memory-hard
  verification from becoming a DoS amplifier.
- **Single source of truth** — the widget CSS/driver/WASM assets are shared by
  the Rust and PHP implementations (`packages/kiwicaptcha-wasm/assets/`).

## Components

| Directory | What | Language |
|-----------|------|----------|
| `packages/kiwicaptcha` | Core engine: issuance, verification, telemetry, widget | Rust |
| `packages/kiwicaptcha-wasm` | WASM solvers (SHA-256 + Argon2id) + embed tooling | Rust → wasm32 |
| `packages/kiwicaptcha-php` | PHP 8.1+ core + Symfony 6.4/7 bundle | PHP (ext-sodium) |

The Rust crate and the PHP SDK are protocol-identical; the PHP test suite pins
its implementation to fixtures generated by the Rust crate.

## Quick start (Rust)

```toml
[dependencies]
kiwicaptcha = { git = "https://github.com/Bel-Consulting-OU/kiwicaptcha" }
```

```rust
use kiwicaptcha::{issue_challenge, verify_solution, ChallengeConfig, PoWAlgorithm, VerifyContext};

let config = ChallengeConfig {
    secret_key: "your-hmac-secret-key".into(),
    algorithm: PoWAlgorithm::Sha256,   // or PoWAlgorithm::Argon2id
    m_kib: 0,                          // Argon2id memory (KiB); 0 for SHA-256
    t: 1, p: 1,
    target_bits: 20,                   // ~1M expected hashes ≈ 2-5 s browser solve
    argon2_target_bits: 8,
    ttl_secs: 120,
    min_duration_ms: None,             // None => derived from difficulty
    auto_tune: false,
    auto_tune_min_bits: 10,
    auto_tune_max_bits: 20,
};

let issued = issue_challenge(&config, "login", &client_ip, now_unix, 0)?;
// store issued.record (single-use), send issued.challenge to the widget

// verify
let ctx = VerifyContext { record: &record, secret_key: &config.secret_key,
    counter, duration_ms, now_unix, min_duration_ms: 0, expected_scope: Some("login") };
match verify_solution(&ctx) { VerifyOutcome::Valid => { /* allow */ }, _ => { /* reject */ } }
```

Render the widget: `kiwicaptcha::kiwi_widget_html(endpoint, scope)` returns a
self-contained HTML block (styles + WASM solver + driver). The endpoint is the
challenge-issuing route, the scope is the challenge scope; both are
HTML-attribute-escaped. For the defaults (`/api/kcaptcha/challenge`, `login`)
use `kiwi_widget_html_default()`. The driver also exposes
`window.KiwiCaptcha.init/render` for SPAs, and honors `data-kiwi-endpoint` /
`data-kiwi-scope` attributes on the container for standalone backends.

## Quick start (PHP/Symfony)

```bash
composer require kiwicaptcha/kiwicaptcha-php
```

```php
use KiwiCaptcha\Config;
use KiwiCaptcha\Issuer;
use KiwiCaptcha\Verifier;
use KiwiCaptcha\Storage\ArrayStorage;

$config = new Config(secretKey: 'your-32-byte-hmac-secret', targetBits: 20);
$storage = new ArrayStorage(); // or Psr6Storage($cachePool)
$issuer = new Issuer($config, $storage);
$challenge = $issuer->issue('login', $clientIp);   // JSON -> widget

$verifier = new Verifier($storage);
$outcome = $verifier->verify($token, $config->secretKey, 'login', $clientIp);
if ($outcome->isOk()) { /* allow */ }
```

Symfony: two options —
- `kiwicaptcha/kiwicaptcha-php` ships a self-contained Symfony bundle
  (`KiwiCaptcha\Symfony\KiwiCaptchaBundle`).
- `packages/kiwicaptcha/integrations/symfony` is a standalone bundle
  (`BelConsulting\KiwiCaptchaBundle`, Composer package
  `bel-consulting/kiwicaptcha-symfony`) that reuses the verified PHP core:
  register it, configure `kiwi_captcha.secret_key`, add
  `KiwiCaptchaType` to your form, and it ships its own challenge endpoint
  (`POST /kiwi-captcha/challenge`) and inlined widget assets — zero external
  requests, the secret key never leaves your server.
  See `packages/kiwicaptcha/integrations/symfony/README.md`.

## Building the WASM solver

The widget embeds a compiled WASM + wasm-bindgen glue as a single asset
(`wasm/kiwicaptcha-wasm/assets/kiwicaptcha-wasm.js`). Regenerate after
touching the solver:

```sh
packages/kiwicaptcha-wasm/build.sh
```

Pure Rust pipeline (cargo + wasm-bindgen-cli + an optional wasm-opt from
binaryen). No Node.js, no wasm-pack.

## Testing

```sh
# Rust
cargo test --manifest-path packages/kiwicaptcha/Cargo.toml

# PHP
cd packages/kiwicaptcha-php && composer install && vendor/bin/phpunit
```

Rust: 42 tests (bot-detection edge cases, replay/tamper/expiry/scope/IP,
algorithm cross-checks, difficulty range, RFC 6234 vector).
PHP: 26 tests / 50 assertions, pinned to Rust-generated fixtures.
